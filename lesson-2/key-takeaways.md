#GIT
## 1
1.git init : Biến thư mục hiện tại thành một Git repository (nơi Git sẽ theo dõi sự thay đổi của file).

2.git add <tên_file> : Đánh dấu các file sẽ được commit (bỏ vào vùng staging).

3.git add . : Đánh dấu tất cả các file sẽ được commit (bỏ vào vùng staging).

4.git commit -m "Test" : Lưu lại trạng thái hiện tại của project kèm ghi chú mô tả.
